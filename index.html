¿Que es HTML?

HTML (HyperText Markup Language) es el lenguaje que define la estructura de una página web, incluyendo textos, imágenes, botones y enlaces.

Aprende HTML

¿Que es CSS?

CSS (Cascading Style Sheets) es el lenguaje que define la apariencia visual de una página web: colores, tamaños, diseño, animaciones y más.
